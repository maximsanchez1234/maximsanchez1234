## Proyectos

### ASIR-AI — Administrador inteligente de sistemas

Proyecto orientado a la administración y monitorización centralizada de varios servidores Linux.

El objetivo es desarrollar una plataforma web desde la que sea posible consultar el estado de los servidores, supervisar recursos y servicios, centralizar incidencias y utilizar inteligencia artificial como apoyo para el diagnóstico de problemas.

Principales áreas del proyecto:

- Monitorización de CPU, memoria y almacenamiento
- Supervisión de servicios
- Gestión y análisis de logs
- Sistema de alertas
- Gestión de incidencias
- Administración de varios servidores Linux
- Control de acceso mediante usuarios y roles
- Auditoría de acciones
- Despliegue mediante Docker
- Integración de un asistente basado en IA para análisis de errores

El proyecto se encuentra actualmente en desarrollo.
